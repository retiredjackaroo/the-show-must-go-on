# The Show Must Go On

Standalone Quartz website for the Dungeons & Dragons campaign **The Show Must Go On**.

## Website

<https://retiredjackaroo.github.io/the-show-must-go-on/>

## Local development

```bash
npm ci
npm run quartz -- build --serve
```

The site deploys to GitHub Pages automatically from the `v5` branch through `.github/workflows/deploy.yml`.
